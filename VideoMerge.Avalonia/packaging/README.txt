VideoMerge desktop
==================

Windows
  Double-click VideoMerge.Avalonia.exe

macOS
  Open VideoMerge.app
  First launch: System Settings → Privacy & Security → Open Anyway
  (the app is not Apple-signed)

Linux
  chmod +x VideoMerge.Avalonia
  ./VideoMerge.Avalonia

FFmpeg
  ffmpeg and ffprobe must be installed and on PATH,
  or pick ffmpeg.exe / ffmpeg from the app window.

  Windows: https://www.gyan.dev/ffmpeg/builds/
  macOS:   brew install ffmpeg
  Linux:   sudo apt install ffmpeg
